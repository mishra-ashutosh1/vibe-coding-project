# AI-Assisted Projects

A collection of practical applications and prototypes built through AI-assisted development, experimentation, and iterative problem-solving.

I am an operations, reporting, analytics, and automation professional with 15+ years of experience. These projects show how I apply that background to interactive web applications, data visualization, personal-finance tools, productivity, and business-process automation.

> **Project scope:** These are learning builds, demos, or prototypes—not representations of any employer's systems. Any HR/onboarding proof of concept is separate and uses fictional data only.

## Projects

### 1. Backlog & Beyond — Task Management
A lightweight browser-based task manager for organizing work and keeping task data portable.

- Create and track tasks by status, priority, category, and due date
- Search, filter, sort, and review progress summaries
- Switch themes and customize the appearance
- Import/export tasks using Excel-compatible files
- Save a JSON backup for portability

**Live demo:** [backlog-and-beyond.netlify.app](https://backlog-and-beyond.netlify.app/)  
**Source:** [BacklogAndBeyond](./BacklogAndBeyond)

### 2. NiveshLens — Portfolio Analytics
A portfolio-analysis project exploring investment information, financial data, and user-facing analytics.

**Live demo:** [niveshlens-ashutosh.netlify.app](https://niveshlens-ashutosh.netlify.app/)  
**Source:** [NiveshLens](./NiveshLens)

### 3. Business Dashboard — Interactive KPI Visualization
A browser-based dashboard for exploring business measures through interactive charts and filters. It demonstrates an alternative way to present selected reporting insights in a shareable web experience; whether it can replace a BI platform depends on data security, refresh, access, and collaboration needs.

**Live demo:** [business-dashboard-ashutosh.netlify.app](https://business-dashboard-ashutosh.netlify.app/)  
**Source:** [BusinessDashboard](./BusinessDashboard)

### 4. Indian Income Tax Calculator
A practical calculator interface for exploring Indian income-tax scenarios. Review calculations against current official rules before relying on results for tax decisions.

**Live demo:** [income-tax-calculator-ashutosh.netlify.app](https://income-tax-calculator-ashutosh.netlify.app/)  
**Source:** [IncomeTaxCalculator](./IncomeTaxCalculator)

### 5. ActiveDay — Productivity & Wellbeing
A productivity-oriented application exploring everyday routines and user-focused interaction. This project is a work in progress.

**Live demo:** [activeday.netlify.app](https://activeday.netlify.app/)  
**Source:** [ActiveDay](./ActiveDay)

### 6. Citizen Developer — Microsoft Power Platform
A business-process automation project demonstrating how Power Apps, SharePoint, Power Automate, and Power BI can work together for task capture, manager review, notifications, and reporting.

**Source:** [CitizenDeveloper](./CitizenDeveloper)

## Development approach

AI coding assistants are used as collaborators to accelerate exploration, implementation, and iteration. Generated code and outputs still require review, testing, and validation. The goal is to build useful working demos while continuing to improve engineering judgment and delivery quality.
