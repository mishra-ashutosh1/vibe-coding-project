# Citizen Developer — Task Tracker

**Stack:** Power Apps + SharePoint + Power Automate + Power BI (end-to-end automation)

## Overview

The goal was simple: make task tracking easier for both team members and managers. This project helped me understand how different Microsoft Power Platform services work together to build a practical business solution.

## How it works

- Team members can create tasks, set their own priority, and update progress
- Tasks are stored in a SharePoint List
- Managers have a separate screen where they can review tasks, override priorities, and assign final rankings
- Manager screens are secured, so only authorized users can access them
- Once a task is marked as complete, Power Automate sends an email notification to both the task owner and the manager
- Power BI provides a live dashboard, giving the team visibility into the current status of all tasks
